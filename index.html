What NOVA can do

A customizable AI workspace built as a single HTML file, designed to be usable on phones, tablets, laptops, and desktop browsers.

Works offline

Open this HTML file in a modern browser. The editor, calculator, starter references, notes, local chat history, and downloads do not require an internet connection. The built-in offline helper is rule-based, not a full language model, so it cannot match ChatGPT or other large AIs by itself.

Connect stronger models

Use your own supported API credentials for OpenAI, Groq, OpenRouter, Gemini, or Claude, or point the OpenAI-compatible option at a local service. You must follow each provider's account terms and usage limits. An ordinary ChatGPT/Claude web subscription does not automatically provide API access.

Knowledge is not infinite

No single HTML file can hold every fact ever learned, and no current model knows everything. The knowledge library lets you build a private collection from your own class notes, references, and code. The assistant can pull matching excerpts from those notes into online requests.

File support

Create and download TXT, Markdown, HTML, CSS, JavaScript, Python, JSON, CSV, XML, SQL, and shell files. Import plain text and source files. This single-file build does not parse PDF or Word documents directly; convert them to text first and attach that text.

Quick setup for an online or local model

1. Open AI & Settings. 2. Choose a provider and add a model ID plus API key if needed. 3. Apply connection and select that provider in AI Chat. API keys are not stored after a page refresh. For best results, use a model ID currently available in your provider account.

Version 1.0 • Single-file build

All app code is contained in this HTML file. No sign-in, account system, hidden analytics, or remote scripts are included. Some online APIs may block direct browser calls; if that happens, use a compatible local endpoint or host the file from a local web server.
